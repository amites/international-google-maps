# Single Purpose Description

Chrome Web Store field: **Privacy practices → Single purpose**
Paste the text between the markers into the form. Plain text only.

---BEGIN PASTE---
This extension has one purpose: to display the internationally recognized place names "Lake Ontario" and "Gulf of Mexico" to the user while they browse Google Maps.

It does this in two ways. First, it rewrites the visible text, aria-label, and title values on the Google Maps page where the alternate names appear, so that page text and screen-reader output use the international names. Second, because Google Maps draws geographic labels inside a private WebGL canvas that an extension cannot read or rewrite, it draws a small non-interactive text label at the correct screen position for each of those two locations, repositioned from the map coordinates in the page URL as the user pans and zooms.

The extension does nothing else. It runs only on Google Maps, affects only what the current user sees in their own browser, does not alter Google's data, and can be turned off at any time from its toolbar popup.
---END PASTE---
